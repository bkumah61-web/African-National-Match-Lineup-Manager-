Queue FIFO Logic & Architecture

Match Management Data Structure Explained

1. About the Queue

In computer science and real-world tactical operations, a Queue is a linear data structure that follows the FIFO (First-In, First-Out) principle. The element added first is the first one processed.

2. Positions

Front (Index 0): The head of the queue representing the active element ready for immediate execution (the next player ready to sub onto the pitch).
Rear (End): The tail where newly queued players are appended.

3. WHY QUEUE is USED

Ensures strict chronological order, prevents tactical confusion during high-pressure matches, and provides fair, reliable squad management.

4. THE FLOW

Enqueue (`push`): Appends bench player to the rear.
Priority Next (`unshift`): Places player at Index 0 for urgent substitution.
Dequeue (`shift`): Removes player from Index 0 to step onto the field.
